# 📊 Electric-Vehicle-Charge-and-Range-Analysis

## 📖 Project Overview

**Electric Vehicle Charge and Range Analysis** is an interactive Business Intelligence project developed to analyze Electric Vehicle (EV) charging infrastructure, battery performance, driving range, and vehicle specifications using **Tableau**, **MySQL**, **Flask**, **HTML**, **CSS**, and **JavaScript**.

The project integrates an interactive Tableau dashboard with a responsive Flask-based web application, enabling users to explore EV data through dynamic visualizations, filters, and analytical insights. It helps users compare EV models, understand charging infrastructure, and make data-driven decisions using modern data visualization techniques.

# ⚙️ Installation

## Step 1

Clone the repository.

```bash
git clone https://github.com/komalnagendra/Electric-Vehicle-Charge-and-Range-Analysis.git
```

---

## Step 2

Navigate to the project directory.

```bash
cd Electric-Vehicle-Charge-and-Range-Analysis
```

---

## Step 3

Install the required dependencies.

```bash
pip install -r requirements.txt
```

---

## Step 4

Set up the MySQL database.

- Install MySQL
- Create the database

```sql
CREATE DATABASE EV_ANALYSIS;
```

- Import the EV dataset into the database.

---

## Step 5

Run the html application.

---

## Step 6

Open your browser.

```
http://127.0.0.1:5000
```
